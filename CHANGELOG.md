# Changelog

## 0.1.0

- Initial release: hosted Writer MCP server (`https://api.writer.com/v1/mcp`) with OAuth sign-in.
- Playbooks: list, get, and run playbooks; upload files for run inputs.
- Runs: get status, list runs, get run output, resume, and cancel.
- Deliverables: list owned deliverables and download deliverables.
